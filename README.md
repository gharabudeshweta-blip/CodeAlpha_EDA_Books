# 📊 Exploratory Data Analysis (EDA) - Books Dataset

## 📌 Overview
This project focuses on analyzing book data collected through web scraping. The goal is to identify patterns, trends, and insights using data visualization.

## 📂 Dataset
books_data.csv

## 🎯 Objectives
- Analyze book prices and ratings  
- Identify trends in ratings  
- Visualize data using Matplotlib  

## 🛠 Tools Used
- Python  
- Pandas  
- Matplotlib  
- Jupyter Notebook  

## 📊 Key Insights
- Most books have medium ratings (3–4 stars)  
- Prices are mostly in a moderate range  

## ✅ Conclusion
The dataset shows a balanced distribution of book prices and ratings, useful for basic market understanding.
